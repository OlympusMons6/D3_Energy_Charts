Behind the charts

Small files. One clear workflow.

Find → load → format → measure → bind → scale. Each chart follows the D3 workflow from the activity.

How the code works
  1. Load and validate. Each chart loads its own CSV once with d3.csv(). Exact column names are checked, and numeric strings are converted explicitly.
  2. Measure and scale. ResizeObserver watches each chart’s width. The SVG, scales and axis ticks are recalculated for the available space.
  3. Bind and draw. .data().join() reuses marks when the chart redraws. Linear scales position numbers, a band scale positions bars, and d3.pie() with d3.arc() builds the donut.
  4. Keep responsibilities clear. charts/scatter.js, donut.js, bar.js and line.js own their charts. utils.js shares validation, colours, axes, resizing and accessible tables.
  5. Keep the data honest. Means remain means, missing values are not silently converted to zero, and the price line uses straight segments between observed years.

The included README explains the code, data choices and local setup in more detail.
